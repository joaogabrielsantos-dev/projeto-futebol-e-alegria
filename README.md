# Projeto Futebol e Alegria

Projeto web desenvolvido para uma organização social que utiliza o futebol e a educação como ferramentas de inclusão social, desenvolvimento pessoal e criação de oportunidades para crianças e jovens.

## Sobre o projeto

O Projeto Futebol e Alegria tem como objetivo apresentar uma plataforma web para uma organização social voltada ao desenvolvimento de projetos esportivos e educacionais.

A plataforma permite apresentar a organização, seus projetos sociais, formas de participação, possibilidades de doação e cadastro de pessoas interessadas em contribuir com a iniciativa.

O projeto foi desenvolvido como atividade acadêmica do curso de Engenharia de Software, aplicando conceitos de desenvolvimento web, estruturação semântica, responsividade, acessibilidade e organização de projetos.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Páginas do projeto

### Página inicial

Apresenta informações sobre o Projeto Futebol e Alegria, sua história, princípios, equipe, conquistas, projetos sociais, notícias e formas de contato.

### Projetos

Apresenta os principais projetos desenvolvidos pela organização, além de informações sobre voluntariado e formas de realizar doações.

### Cadastro

Página destinada ao cadastro de interessados, contendo formulário com informações pessoais e campos para contato e endereço.

## Funcionalidades

- Navegação entre as páginas do projeto
- Apresentação institucional da organização
- Exibição dos projetos sociais
- Área de voluntariado
- Informações sobre doações
- Formulário de cadastro
- Validação de campos do formulário
- Máscara para CPF
- Máscara para telefone
- Máscara para CEP
- Seleção de forma de pagamento
- Simulação de confirmação de doação
- Layout responsivo para diferentes tamanhos de tela

## Acessibilidade

O projeto busca seguir boas práticas de acessibilidade e usabilidade, utilizando:

- Estrutura semântica do HTML5
- Hierarquia adequada de títulos
- Textos alternativos para imagens
- Campos de formulário identificados
- Contraste adequado entre textos e fundos
- Navegação organizada
- Estrutura compatível com diferentes tamanhos de tela
